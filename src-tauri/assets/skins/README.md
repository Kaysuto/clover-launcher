# Skins d'origine Minecraft

Textures officielles Mojang, extraites de `assets/minecraft/textures/entity/player/` du
client Java 26.2 (SHA-1 `2dc72797acbc1b63fc16a11c4ac393605f453754`). Elles servent de repli
avant l'installation du jeu ou hors ligne. Les textures du client installé restent prioritaires.

Minecraft et ces personnages appartiennent à Mojang/Microsoft. Ces fichiers ne fixent pas
la version du jeu lancé : celle-ci reste pilotée par le manifeste Clover signé.
