Chat Heads affiche la tête du joueur à côté de chacun de ses messages dans le chat. On repère d'un coup d'œil qui parle, même quand le chat défile vite.

### Bon à savoir

- Ses réglages sont accessibles depuis Mod Menu.
- Si les têtes n'apparaissent pas sur un serveur, choisis le mode de détection « Heuristic only » dans ses réglages : il fonctionne partout, mais peut parfois se tromper de joueur.
